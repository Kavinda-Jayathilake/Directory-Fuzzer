# Directory Fuzzer

A simple web directory fuzzer written in Python.

This project is built to understand how directory and file discovery works on web servers,
not to rely on existing fuzzing tools.

---

## Purpose

- Learn how web directory fuzzing works
- Practice HTTP requests and response handling
- Understand status codes and server behavior
- Build the fuzzer step by step

---

## Current State

- Sends HTTP requests to a target URL
- Uses a wordlist to test possible directories
- Prints responses for discovered paths

---

## Usage

> Scan only web applications you own or have permission to test.
